# Introduction to Containers and Docker

This repository contains materials and exercises from the Frontend Masters course "Complete Intro to Containers" by Brian Holt.

## Course Overview

Learn the fundamentals of containers and Docker, including:

- Container basics and concepts
- Docker commands and workflow
- Building custom images
- Docker Compose
- Kubernetes introduction
- Container orchestration

## Getting Started

1. Visit the course website: [Complete Intro to Containers](https://containers-v2.holt.courses/)
2. Clone this repository
3. Follow along with the exercises

## Prerequisites

- Basic command line knowledge
- Basic JavaScript understanding
- Docker installed on your machine

## Course Structure

The repository follows the course structure with hands-on examples and exercises for:

- Basic container concepts
- Dockerfile creation
- Multi-container applications
- Container networking
- Volume management
- Container orchestration basics
